# 全局标量融合受控实验报告

2026-11-08 完成三种子开发集训练/验证和预锁 PV-896 外部评估。Kaggle 私有 GPU 作业：[开发集训练 v1](https://www.kaggle.com/code/zh0416/pv-dmsf-global-scalar-fusion)、[外部评估 v1](https://www.kaggle.com/code/zh0416/pv-dmsf-external-pv896)，均为 Tesla T4 且状态 COMPLETE。

## 结论

分割头只读取 `[phi(Fq), A_selected]`，空间对照选 `A_spatial`，融合组选 `A_fused=sigmoid(beta)A_spatial+(1-sigmoid(beta))A_semantic`。这消除了首轮头部同时读取三张 CAM 的旁路。该受控实验中，融合在三种子验证和锁定外部集上均**没有稳定优于空间单路**；真实 GeoRSCLIP 文本相对固定随机文本也**没有稳定优势**，不能声称预训练语义独立有效。

外部 PV-896 组宏 Dice 约 0.58–0.60，明显低于同类 PV08 开发集约 0.88。支持辅助校准压低了空光伏查询上的虚假 CAM 亮点，但未提高总体外部 Dice。结果显示此模型在该预锁外部协议下有明显性能下降，不能声称可靠跨数据集泛化。

## 受控设置

冻结 DINOv3-SAT ViT-L/16 第24层和 GeoRSCLIP RS5M ViT-B/32 文本编码器；GeoRSCLIP 图像塔在严格加载后删除，不接入旧滑窗 CAM。固定提示为 `a satellite image of ground-mounted solar panel arrays`。共享 `phi` 投影支持/查询 patch 到256维，支持前景投影特征先汇聚原型，再与查询逐 patch 余弦相似；文本经可训练三层 `g` 和独立 `psi` 到256维，再与查询投影逐 patch 余弦相似。两路各有可训练 CAM 修正器。

全部对照使用 `Conv3x3(257,64) -> ReLU -> Conv1x1(64,1)`、BCEWithLogits + Dice + 0.2×空间 CAM Dice、AdamW `1e-4`/weight decay `1e-4`、batch 4、20 epoch、260 张训练查询每轮各一次及相同种子内同一跨组 episode。每组1,300次优化器更新，按95张固定验证查询的组宏前景 Dice 选最佳轮次；logits 阈值固定0。种子为42/43/44。

`minmax` 为 SSPNet DMSF 融合参考中的逐图 min-max，**不是完整 SSPNet 复现**。`calibrated` 在32个源训练 episode 中用查询训练标注估计各 CAM 的初始源阈值/温度，随后在源训练中优化；目标阶段只用支持掩膜对阈值做0.25收缩更新。空间支持分数用4×4分块留出原型，避免同一 patch 自评价。目标查询真值不进入校准、前向、权重或阈值选择。beta 初值为0.7（空间权重0.668）或 `logit(0.85)`；随机文本固定归一化向量，文本 MLP/psi 和训练预算不变。

## 空查询与外部协议

PV08 验证95张查询没有全空标注，空查询诊断来自预锁 PV-896 的48张查询，其中21张无光伏。空间单路在这21张上的三种子平均 CAM 峰值：min-max 为约 `0.998/0.999/1.000`，校准为 `0.302/0.354/0.379`；CAM>=0.5 的 patch 比例分别约 `45.6%/27.3%/33.0%` 与 `0.58%/0.73%/1.61%`。因此校准确实缓解逐图 min-max 强制相对亮点，但其外部组Dice相对空间 min-max 三种子差为 `-0.01148/-0.04897/+0.00543`，均值 `-0.01834`，不能据局部诊断宣称总体改善。

外部协议在开发集训练完成前锁定，详见 [`external_protocol.json`](external_protocol.json)，SHA-256 `a444aa36539b92aba6bd7943d0033f75b3b7b77cd6500a6e34e77b7fac79f50a`。8张支持来自北纬24度以南的8个原始场景，48张查询来自北纬26度以北的6个不同场景；原清单记录每张图的源GeoTIFF日期、EPSG:4326范围、近似米级GSD、0/255光伏标签定义和文件哈希。所有30个已由PV08验证选出的检查点原样评估，未用PV-896查询标签选模、调beta或调阈值。原生896像素影像由四块448像素独立编码成56×56 patch 网格，冻结预处理与第24层不变；编码几何变更仍是外部评估中的一项限制。

PV-896 来源文档声明无PV08影像，原始场景与本次支持/查询场景均分离；但PV08缺真实footprint，无法做两来源的严格空间叠置核验。PV-896部分源SHP文件名带“不确定”，锁定样本中7/8张支持和24/48张查询带此标记，标签质量可能影响外部指标。GSD为从仿射变换按纬度估算的米/像素，不是来源认证的传感器GSD。

## 结果核验

本地跨阶段44项回归测试通过；外部独立作业3项测试通过。[`local_verification.json`](results/local_verification.json) 核对30组源码/协议和检查点哈希、20轮/1,300次更新、每组95张验证查询、逐图聚合、真实验证输入CPU复算，以及旧90张测试分区没有被提取特征、解锁或用于新选模。全量663对仅做结构与字节哈希核验。[`external_verification.json`](results/external_verification.json) 核对30组外部指标聚合、锁定检查点、48张查询覆盖和30条真实输入CPU/GPU输出；最大logits差小于`1e-5`。两次作业中两个冻结编码器的完整参数/缓冲区哈希前后一致，均无梯度；可训练视觉、文本、修正器、beta、校准参数和头部均有有限非零梯度与实际参数变化。示例：种子42的真实文本校准融合，文本MLP梯度范数最大`0.0297`，beta梯度最大`0.000778`、参数变化L2 `0.0272`。这些只证明分支被优化，不证明语言语义贡献。

本地不保存大体积冻结特征缓存；完整GPU输出留在Kaggle。旧第二阶段90张测试的既有结果不作为本实验的独立最终测试，也不参与上表。
